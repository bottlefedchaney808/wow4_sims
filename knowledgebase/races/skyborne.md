# Skyborne (Shen'dorei)

Last verified: 2026-09-19 · `official`[1][5][6] + `wowhead`[12][11]

Windswept elves. Paywalled behind Heroic pack+.[12] Choose Horde or Alliance at creation — not a true neutral race.

## Racials

Shared:

| Racial | Type | Effect |
|---|---|---|
| Walk on Air | active | Glide down 10s, steer. Spell 1259416 | wowhead[12] |
| Wind Blessed | passive | +1% melee, ranged, **and spell** haste. Spell 1259710 |
| Elemental Insight | passive | +5% damage vs Elementals. Spell 1259707 |

Faction second active:

| Faction | Racial | Effect |
|---|---|---|
| Horde Windshaper | Skysight (1259686) | +10% run and **mounted** speed. 30s if no elemental convergence, **15 min** if found |
| Alliance High Order | Read Ley Line (1259705) | +100% health and mana regen. 15s if no ley line, **15 min** if found |

Wowhead combo page shortened Skysight to "10% run speed" and omitted the mounted/duration split — prefer the Skyborne overview tooltips.[11] vs [12]

## Classes and identity

Horde: Earthen Ring / elemental → Shaman. Alliance: Kirin Tor / arcane → Mage. Both get unique druid forms, voices, dances, customizations.[5]

Racial mount: **Galestrider** (crane). Level 40 and Swift 60 color variants.[12]

Start: Zephras Isle 1–12.[5]
