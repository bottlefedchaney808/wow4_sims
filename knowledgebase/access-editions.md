# Access, editions, beta

Last verified: 2026-09-19

Forever **play** is included with an active WoW subscription or game time.[1][2][28]

The **Skyborne race and Zephras starting experience** require Skyborne Heroic Pack or higher.[1][12][26]

## Beta how-to (`official`)[3]

Battle.net → WoW → Game Version → **World of Warcraft: Forever Beta** (In Development) → Install → test realm.

Week 1: level cap 20. Later raised to 30. More zones/dungeons/BG open over the test. Server Slam TBA.
