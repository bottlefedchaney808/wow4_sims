# Design pillars and lore frame

Last verified: 2026-09-19

## Four pillars (`official`)[5][25]

1. **Approachable and familiar** — additions must feel like they belong in Classic. No flying, no level scaling.
2. **World as the main character** — leveling equals endgame in importance. Local stories over constant world-saving.
3. **Journey before destination** — cap 60 forever. Catch-up is playing, not a paid boost. No WoW Token / paid level boost announced.[27]
4. **Protect social experiences** — camps, realmless-but-not-one-megaserver, two-part names, language preference.

## Found photographs (`official`)[6]

Chris Metzen's SoD phrase, reused: content that feels like it was always in 2004 Azeroth.

Three buckets:

- **Anticipated** — Hyjal
- **New but familiar** — Riverglades
- **Unexpected** — Zephras / Skyborne, used sparingly

Time bubble: after *Warcraft III Reforged: Forsaken Kingdom*, before Molten Core / Dark Portal reopen.[6][7] Classic raids return later as revamped iconic content, not all on day one.[9][26]
