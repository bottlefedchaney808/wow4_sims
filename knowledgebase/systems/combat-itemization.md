# Combat and itemization

Last verified: 2026-09-19 · `official`[4]

## Combat feel

Classic pacing on purpose. Solo ordinary mob **~10–15 seconds**. Dungeons still want CC (Poly, Banish, Fear, Root). Threat, focus fire, don't indiscriminately AoE.[4]

Classes stay simple-with-depth and **not homogenized**. Gaps stay (Paladin still has no interrupt).[4]

Talent trees: same row count as 1.12, milestones at **11 / 21 / 31**, **new 16-point milestone**. Some 1.12 talents unchanged, some buffed. Buff-gate talents (Divine Spirit, Blessing of Kings, Improved Mark of the Wild) are **baseline**.[4]

All 27 trees intended as viable group options (`press`)[26].

## Stats (`official`)[4]

Kept Classic stats, then reworked/added:

- **Hit** merged: spell + melee + ranged.
- **Crit** merged the same way. Helps hybrids (Ret, Enh) and lets Warrior/Hunter/Rogue hit matter for Taunt/Poison/Trap.
- Weapon skill still exists; **less weapon skill per item** so Edgemasters-type items are not auto-BiS.
- Bonus healing now includes **1/3 bonus damage**.
- New: chance to **reduce parry/dodge** taken (expertise-like).
- Caster weapons grant **spell damage and healing** from leveling.
- Trinkets more situational (Worgenbane Talisman; environment: Woodlands/Mountains/Deserts; creature-type e.g. X'caliboar).
- Every dungeon drop re-examined. Unique dungeon boss items are **blue**. Set bonuses improved.
- Quest rewards expanded (Mor'ladim ring for casters; Nesingwary spellsword).
- World-drop epics improved; hundreds of new rare-creature drops.

`press` also lists expertise-like stats and "later-era stats."[26] Until spell IDs exist, sim engine should expose:

`hit`, `crit`, `weapon_skill`, `spell_power`, `healing_power` (with 1/3 SP from heal), `expertise_like`, `armor_pen? unknown`

Do **not** import SoD or WotLK haste/mastery unless datamined.

## Leveling XP (`press`)[27]

XP-to-level unchanged vs Classic. Dungeon **mob** XP down; dungeon **quest** XP on first clear up — chain-running one instance nerfed. 1000+ quests carry the route. Working figure ~150 hours 1–60 (boost-site estimate, not Blizzard).
