# Transmog

Last verified: 2026-09-19 · `official`[4]

Opt-in. Classic visual preset disables it on first launch. Collect appearances even while disabled.

- Uncommon/Rare **BoP dungeon** appearances granted to **all eligible looters** when looted (no need vs greed for tmog).
- **Epic raid** appearances only for the player the item binds to.
- Poor/Common appearances on loot, no bind required.
- Armor type still binds (plate→plate, cloth→cloth).
- High-level appearances locked until **level 60** except rare cosmetics.
- Own hidden helm/cloak still visible to people with tmog off.

Sim: ignore.
