# Legacy system

Last verified: 2026-09-19 · `official`[4] + `wowhead`[16]

Alt-friendly account progression inspired by Hardcore's "always someone leveling" energy, without permadeath.

## Points (`official`)[4]

- Earn **Legacy Points** from Legacy Challenges (level a class, skill milestones, etc.).
- Spend in trees: **Professions**, **Adventure**, **Resourcefulness**. Spend is **per character**. Points earned are **account-wide**.
- Launch spend cap: **16** per character. Can earn up to **65** at start. Overflow feeds a **cosmetic Legacy Reward Track** (e.g. Spectral Bear Cub) — no combat power.
- System is designed to grow: more challenges, perks, caps, columns, maybe new trees.

Examples:

- Adventure: **Well Rested** — more rested XP and higher rest cap.
- Professions: **Bountiful Harvest** — more mine/herb/skin yields.
- Resourcefulness: **Reagent Economy** — strip reagent cost from class abilities.

Also: TBC-style mounts — pay for **riding skill**, mount comes with it.[4]

## Challenges (`wowhead` beta)[16]

Most basic challenges = 1 point. Categories seen: class 25/45/60, profession 150/225/300, PvP ranks 3/7/10/13/14, BG exalted (including **Darkspear Islands** reps: Darkspear Raiders / Theramore Expeditionary Force), dungeon/raid clears, Explore Azeroth, Dungeon Set 2 questline.

Respec at class trainer; beta cost **10 silver** — unknown if it scales.[16]

## Hardcore interaction (`official`)[4]

Collections + Legacy Points account-wide **across rulesets except Hardcore inbound**. Hardcore progress can leave Hardcore; other rulesets do not feed Hardcore.

Sim note: Legacy is mostly QoL (rest, gather, reagents). Combat-relevant nodes must be listed before they enter a sim. Default sim profile: 16 points spent, document the loadout.
